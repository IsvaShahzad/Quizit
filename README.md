# 📱 Quiz App (Flutter)

An interactive quiz application built using Flutter, focused on clean UI and smooth user experience.

## 🚀 Features

* Multiple-choice questions
* Instant answer feedback
* Score tracking system
* Final result screen
* Simple and responsive design

## 🛠️ Tech Stack

* Flutter (Dart)
* Material Design
